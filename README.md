## Dashboard Power BI

El archivo `PowerBI/olist_dashboard.pbix` contiene un dashboard de 6 páginas:

| Página | Descripción |
|---|---|
| `Overview` | KPIs principales: revenue total, ticket promedio, pedidos y % entregas |
| `Ventas` | Evolución mensual de revenue (gráfico de líneas) |
| `Top 10` | Top 10 categorías por revenue (barras horizontales) |
| `Ticket Promedio` | Ticket promedio por categoría de producto |
| `Pedidos por Estado` | Distribución de pedidos por estado de Brasil |
| `Entregas` | Porcentaje de entregas a tiempo por estado |
